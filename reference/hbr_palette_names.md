# Names of the built-in colour palettes

Names of the built-in colour palettes

## Usage

``` r
hbr_palette_names()
```

## Value

A character vector of palette names accepted by \[hbr_palette()\].

## Examples

``` r
hbr_palette_names()
#>  [1] "haplobreed" "okabe_ito"  "npg"        "nature"     "lancet"    
#>  [6] "jama"       "nejm"       "jco"        "aaas"       "frontiers" 
```
