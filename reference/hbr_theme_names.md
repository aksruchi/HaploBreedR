# Names of the built-in ggplot2 themes

Names of the built-in ggplot2 themes

## Usage

``` r
hbr_theme_names()
```

## Value

A character vector of theme names accepted by \[hbr_theme()\].

## Examples

``` r
hbr_theme_names()
#>  [1] "haplobreed" "minimal"    "classic"    "bw"         "light"     
#>  [6] "dark"       "void"       "linedraw"   "economist"  "scientific"
```
